今回の追加修正（v1.10.8）:
・トレーニング完了後は「終了」ボタンを表示せず、「完了」だけを押せる状態に整理
・腹囲引き締めを目的としたメニュー選定を見直し
・デッドバグ、サイドプランク（膝つき）、プランク、デッドバグ・タップなどの体幹種目を優先
・スロースクワット、ヒップリフト、バードドッグなど全身・下半身も腹囲目的の候補として優先順位を調整
・壁プッシュアップなど腹囲目的との関連が比較的低い種目は優先順位を下げた
・軽めメニューでも腹囲目的の主力種目を候補に含め、負荷は軽めに調整

v1.10.8確認項目:
・トレーニング完了時に「終了」と「完了」の2ボタンが並ばず、「完了」のみ押せること
・5分/10分/15分の各コースで腹囲目的の主力種目が適切に候補へ入ること
・同じ種目の連続を避けつつ、直近7日/28日のバランス調整も維持されること
・軽めを選んだ場合も、腹囲目的の主力種目が無理のない負荷で選ばれること
